# Awesome Fancy Fonts

A curated list of handy tools that generate fancy text, stylish fonts and cool letters for social media bios, captions and nicknames.

## Fancy text generators

- [Fancy Fonts](https://fancysfonts.com/) — free fancy text generator with dozens of stylish font styles; type once and copy beautiful Unicode text for Instagram, TikTok and Discord.
- [LingoJam Fancy Text Generator](https://lingojam.com/FancyTextGenerator) — the classic fancy letters tool with a huge range of Unicode styles.

## Stylish font styles to try

- 𝐁𝐨𝐥𝐝, 𝑖𝑡𝑎𝑙𝑖𝑐 and underlined text for emphasis
- 𝒮𝒸𝓇𝒾𝓅𝓉 and 𝔤𝔬𝔱𝔥𝔦𝔠 alphabets for bios
- Tiny, flipped and mirrored text effects

## Tips

- Keep bios readable: mix one decorative style with plain text.
- Most platforms render Unicode styles natively, so no app install is needed.
